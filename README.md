# Firebase Push Notifications - React App

A modern React application for Firebase Cloud Messaging (FCM) push notifications with a clean UI.

🔗 **[Live Demo](https://fcm-notifications-demo.netlify.app)**

## Features

- Real-time push notifications (foreground, background, and closed states)
- Modern responsive UI with Tailwind CSS
- Test notification interface
- Animated notification toasts
- FCM token management

## Tech Stack

React • Firebase • Tailwind CSS • Axios • Vite

## Installation

```bash
# Clone the repository
git clone https://github.com/orbitcoretech/react-fcm.git
cd react-fcm

# Install dependencies
npm install

# Start dev server
npm run dev
```

## Build

```bash
npm run build
```
